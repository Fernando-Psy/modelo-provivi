# Site Priscila Borges Moraes — Visão geral

## Descrição

Website em React (Vite) + TailwindCSS para apresentação profissional e contato, com páginas institucionais e conteúdo em pt-BR.

## Páginas

- Home (`/`): Hero, Áreas de atuação, Sobre, Contato
- Blog (`/blog`)
- Vídeos (`/videos`)
- Orientações (`/documentacao`)
- FAQ (`/faq`)
- Privacidade (`/privacidade`), Termos (`/termos`), Cookies (`/cookies`)

## Notas técnicas

- SPA com React Router DOM; regras de rewrite já configuradas para deploy.
- TailwindCSS para estilos e layout responsivo.
